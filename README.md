# 📚 大学日程计划 v3.0

> 专为中国大学生打造的学习效率与日程管理工具 —— **零依赖、本地存储、手机直连**

把你的学习计划、考试倒计时、作业截止、习惯打卡、番茄专注全部装进一个手机能直接打开的网页 App。数据存在你自己电脑上，隐私安全，永久免费。

---

## 🎯 解决什么问题

你是不是也这样：
- 📱 手机上记了计划，但**看不到进度**，复习计划写了就忘
- 📋 作业截止日、考试日期散落在各处，**快到了才发现**
- ⏰ 想专注学习，但没有番茄钟统计，**不知道时间花在哪**
- ✅ 习惯坚持了几天就断，**没有连续打卡的成就感**

**大学日程计划**把这些问题一次性解决：在电脑上一键启动，手机打开网址就能看、能改、能打卡。

## 🚀 快速开始（小白必看）

### 方式一：一键启动（推荐）

**前提**：电脑已装 Python 3.10+（[点这里下载](https://www.python.org/downloads/)，安装时勾选 "Add to PATH"）

```bash
# 1. 下载项目
git clone https://github.com/yyu520920-wq/student-assistant.git
cd student-assistant

# 2. 一键启动（自动初始化 + 开启服务）
python start.py
```

**Windows 用户**：直接双击 `start.bat` 即可，无需敲命令。

启动后会看到：

```
====================================================
  📚 大学日程计划 v3.0 — Web 服务已启动
====================================================
  💻 本机访问：http://127.0.0.1:5000
  📱 手机访问：http://192.168.1.100:5000
  （手机需与电脑连接同一个 WiFi）
----------------------------------------------------
  按 Ctrl+C 停止服务
====================================================
```

### 方式二：手机访问（关键步骤）

1. **确保手机和电脑连同一个 WiFi**（比如同一个家里的 WiFi、同一个校园网）
2. 在手机浏览器地址栏输入上面显示的 **📱 手机访问地址**（如 `http://192.168.1.100:5000`）
3. 手机上就能看到完整界面，可以添加任务、打卡、看计划了！

> 💡 **小提示**：把这个网址加入手机书签，下次直接打开。网址不变（只要电脑 IP 不变）。

### 方式三：仅用电脑浏览器

启动后电脑会自动打开浏览器，访问 `http://127.0.0.1:5000` 即可。

## 📖 小白案例教程

下面用一个**真实场景**带你完整走一遍：期末复习周，怎么用这个工具安排好一切。

### 案例：期末考试复习规划

#### 第1步：录入考试日期

打开手机 → 点底部 **「计划」** 标签 → 点 **「+ 添加」**：

```
课程：高等数学
类型：期末考试
日期：2026-07-25
地点：教1-301
```

保存后，你会看到一条带进度条的考试倒计时：

```
高等数学 期末考试                    剩6天
[████████████████████░░░░░░░░░░]
📅 2026-07-25 · 📍 教1-301 · 第1-4章
```

进度条会随时间推移自动变长，**一眼看出复习紧迫度**。

#### 第2步：把复习任务拆成子任务

点底部 **「任务」** 标签 → 右下角 **「+」**：

```
任务标题：高数期末复习
清单：📚 学习
优先级：🔴 高
截止日期：2026-07-24（考试前一天）
四象限：🔥 重要且紧急
子任务：
  复习第一章极限与连续
  复习第二章导数与应用
  复习第三章中值定理
  做近三年期末真题
  错题回顾
```

保存后，任务列表显示子任务进度：`📋 0/5 子任务完成`。每完成一个，回去勾掉，**看着进度条填满很有成就感**。

#### 第3步：每天用番茄钟复习

进入 **「我的」** 标签 → 番茄专注区 → 点 **「🍅 记录25分钟」**。

学完一个 25 分钟就记录一次。一天下来，今日番茄数 +1 +1 +1……**数字增长就是你的努力证明**。

#### 第4步：养成每日复习习惯

点底部 **「习惯」** 标签 → 右下角 **「+」**：

```
习惯名称：每日高数复习2小时
图标：📐
频率：每天
```

每天复习完点 **「打卡」**，连续天数 🔥 自动 +1。**断了归零，逼自己坚持**。

#### 第5步：睡前看今日概览

点底部 **「今日」** 标签，一屏看完：
- 今天上了什么课
- 今天完成了几个任务
- 习惯打卡了没
- 考试还剩几天

**心里有数，睡觉都踏实**。

### 四象限怎么用（重要）

添加任务时选「四象限」，帮你区分轻重缓急：

| 象限 | 含义 | 怎么处理 | 例子 |
|------|------|---------|------|
| 🔥 **重要且紧急** | 必须立刻做 | 马上做，别拖 | 明天交的作业 |
| ⭐ **重要不紧急** | 长期有价值 | 计划时间做 | 背单词、学技能 |
| ⏰ **不重要紧急** | 别人催的 | 能委托就委托 | 帮同学取快递 |
| 💤 **不重要不紧急** | 纯浪费时间 | 尽量少做 | 刷短视频 |

**秘诀**：多花时间在 ⭐ 重要不紧急 的事上（比如每天背单词），它才不会变成 🔥 重要紧急（比如考前通宵背）。

## 💻 命令行使用（进阶）

除了网页，也可以用命令行操作（适合自动化、AI 调用）：

```bash
# 初始化
python scripts/engine.py init

# 今日概览
python scripts/engine.py today

# 添加任务（非交互式，参数驱动）
python scripts/engine.py task add --title "背单词" --priority 1 --due 2026-07-25 --tags 英语,每日

# 查看任务
python scripts/engine.py task list

# 完成任务
python scripts/engine.py task done t1

# 习惯打卡
python scripts/engine.py habit checkin h1

# 记录番茄钟（不阻塞）
python scripts/engine.py pomodoro log --duration 25 --task "背单词"

# 考试倒计时
python scripts/engine.py exam countdown

# 四象限视图
python scripts/engine.py eisenhower

# 导出全部数据
python scripts/engine.py export
```

完整命令列表见 `python scripts/engine.py --help`。

## ❓ 常见问题

### Q1：手机打不开网址怎么办？

**检查 3 点**：
1. 手机和电脑是否连**同一个 WiFi**？（校园网要连同一个 SSID）
2. 电脑防火墙是否放行了 5000 端口？（Windows 首次运行会弹窗，点「允许」）
3. 电脑上的 `python start.py` 是否还在运行？（关掉就访问不了了）

### Q2：换电脑后数据会丢吗？

不会。数据存在 `~/.student-assistant/` 目录。换电脑前：在「我的」页面点「导出全部数据」→ 保存 JSON → 新电脑上把 JSON 放回 `~/.student-assistant/semesters/默认学期/` 对应文件即可。

### Q3：需要联网吗？

**不需要**。整个工具纯本地运行，断网也能用。唯一需要网络的是手机和电脑要在同一局域网。

### Q4：数据安全吗？

**绝对安全**。所有数据存在你自己电脑的 JSON 文件里，不上传任何服务器，没有任何云同步。只有同一 WiFi 下的人能访问（而且要知道你的 IP 和端口）。

### Q5：可以多人共用吗？

可以，但数据是共享的（同一台电脑同一份数据）。如果想隔离，用「多学期」功能给不同人建不同学期。

### Q6：端口被占用怎么办？

启动时指定其他端口：`python start.py 8080`，然后手机访问 `http://电脑IP:8080`。
